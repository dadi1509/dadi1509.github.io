Selected Coursework

PCB Design and Manufacture

A sequence of PCB projects focused on schematic capture, board layout, manufacturing preparation, soldering, bring-up, measurement, and signal-integrity analysis using Altium Designer and lab equipment.

Board 1

555 Timer LED Test Board

Designed and assembled a 5 V NE555 astable timer board targeting approximately 500 Hz and a 60% duty cycle. The board drove four parallel LED branches with different resistor values, then used oscilloscope measurements to verify frequency, duty cycle, output voltage, switching noise, rise time, and load behavior.

Board 2

Return Plane and Decoupling Comparison Board

Built a comparison board using two nearly identical 74AHC14 hex-inverter circuits driven by the Board 1 timer. One circuit followed good PCB design rules with a return plane and close decoupling, while the other intentionally used poor return-pathing and distant decoupling to demonstrate slower rise time, switching noise, and ground bounce.

Board 3

Custom ATmega328P Arduino-Compatible Board

Designed, manufactured, assembled, and debugged an ATmega328P-based microcontroller board with USB Mini interface, Arduino IDE programming support, shield-compatible headers, power distribution, copper pours, decoupling capacitors, and noise comparisons against a commercial Arduino board.
